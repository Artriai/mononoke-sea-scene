# 海坊主 · 浮世之舟

《怪化猫》海坊主篇的可探索网页重绘。电脑使用WASD/方向键移动，拖动画面环顾，E观察；手机使用左下摇杆移动、右侧拖动环顾。

三段可步行的折返楼梯连接四个高度，包含甲板、中庭、侧舱和后舱。五个人物及壁画、天井、地纹为根据原片生成的重绘。镜头对照目录保留45张按内容精选的补充参考帧。建筑高度和舱室连接含推测性补全。

纯静态HTML/JavaScript，没有安装或构建步骤。GitHub Pages发布源选择`main`分支的根目录。网页相对路径适用于项目子目录。

本地可运行`python -m http.server 8765`，再打开`http://localhost:8765/`。上线版使用独立WebP贴图与按需加载的JPG参考图。

使用Three.js r128，MIT许可见THREE-LICENSE.txt。原动画、角色与视频截图的权利属于各自权利人；本项目为基于用户提供材料制作的非官方场景重绘。
