# 海坊主 · 浮世之舟

《怪化猫》海坊主篇的可探索网页重绘。电脑使用WASD/方向键移动，拖动画面环顾，E观察；手机使用左下摇杆移动、右侧拖动环顾。

三段可步行的折返楼梯连接四个高度。v3补齐四层两侧客舱和上层后舱：19个可开门进入的舱室有独立隔墙、顶棚、榻席、被褥、矮桌与柜子；按E或点击中央提示推开房门。关门、墙体与室内家具均有碰撞。舆图可按层查看客舱平面图，并前往门口。

五个人物及壁画、天井、地纹、金底门画为根据原片生成的重绘。镜头对照目录保留45张按内容精选的补充参考帧。19间房是探索补全的布局数量，并非原作确定的房间数；建筑高度与舱室连接也含推测性补全。

纯静态HTML/JavaScript，没有安装或构建步骤。GitHub Pages发布源选择`main`分支的根目录。网页相对路径适用于项目子目录。

本地可运行`python -m http.server 8765`，再打开`http://localhost:8765/`。上线版使用独立WebP贴图与按需加载的JPG参考图。

使用Three.js r128，MIT许可见THREE-LICENSE.txt。原动画、角色与视频截图的权利属于各自权利人；本项目为基于用户提供材料制作的非官方场景重绘。

## 化猫篇 · 第二章

同一站点新增 /bakeneko/：福寿站台、售票站厅、红椅车厢、独立驾驶室、后端间和短检修走道；八位主要人物以透明纸片重绘。八组门可开合，支持电脑键盘和手机摇杆。依据镜头切换检测后的61张精选原片参考重建，连续尺寸、站厅连接和检修走道含推测补全。支持开通日、空车厢、隧道异变与结界秤阵三种画面。海坊主入口在页眉可切换至化猫，新章页眉和标题页可返回海坊主。
